# Veinfire

吸血鬼幸存者类型的 **2.5D** 动作游戏（Unity / C#）。3D 角色在地面移动，斜上方俯视。

## 这一局里有什么

- 开局武器 **针刺**（自动瞄准），升级可选另外 4 件武器，最多同时 4 件
  - 环绕毒牙、血爆脉冲、霜脉光环、裂空鞭笞
- **Shift / 空格** 冲刺（短暂无敌）
- 7 种敌人：杂兵、奔行、坦克、自爆、远程、精英、Boss
- 约 45 秒一次**尸潮**；2 / 5 / 8 分钟各出一只 Boss
- 撑过 **10 分钟** 即胜利
- 掉落：回血、磁铁（吸光经验）、炸弹、宝箱（额外三选一）
- 连斩加经验；伤害数字、击退、受击闪白
- Esc 暂停

## 操作

| 按键 | 作用 |
|------|------|
| WASD / 方向键 | 地面移动 |
| Shift 或 空格 | 冲刺 |
| 鼠标 | 升级 / 新武器三选一 |
| Esc | 暂停 |
| R | 死亡或通关后重开 |

## 第一次打开

1. Unity Hub 打开 `C:\Users\30871\Veinfire`（Unity 6）。
2. 菜单 **Veinfire → 创建原型场景**，点 Play。

自己的 3D 角色：挂 `Rigidbody`、`Player Combat Stats`、`Player Health`、`Player Motor`、`Player Dash`、`Auto Aim Weapon`。Play 时会自动补武器库、刷怪和 UI。不要挂 `Rigidbody 2D`。

升级优先点**新武器**，再点该武器的强化，比只堆移速更有变化。
