## 版本管理

| 字段 | 当前值 | 改哪里 |
|---|---|---|
| 数值表 | `1.0.0` | 本文件页眉 + 下方变更记录 |
| 游戏设计文档 | v2.6.2 | `Veinfire游戏设计文档.md` |
| 全局 JSON | 26 | `Assets/StreamingAssets/BalanceConfig.json` → `version` |
| 元存档 | `MetaFileVersion = 26` | `MetaProgress` / `veinfire_meta.json` |

**怎么升版本**

1. 改 JSON 或 C# 数值后，先改对应源文件，再更新本表对应章节。
2. **只改数、公式不变：** 数值表补丁号 `1.0.x`，`BalanceConfig.version` 可不动或 +1（建议 +1，方便对存档说明）。
3. **改公式 / 上限 / 模式：** 数值表小版本 `1.x.0`，GDD 修订号（如 v2.6.3），`BalanceConfig.version` 与 `MetaFileVersion` 同步上调。
4. 每次改动在文末 **变更记录** 加一行：日期、版本、改了什么、为什么。
5. 不要另起一份平行数值源。专武间隔、怪血、角色六维目前主要在 C#；JSON 里有而 C# 未读的字段见 §偏差。

## 1. 全局公式（代码）

| 公式 | 实现 |
|---|---|
| 升级经验 | `30 + 14 × (当前等级 − 1)` → `LevelDirector.XpRequiredFor` |
| 玩家伤害 | `Damage × Might × (1 + 狂斩伤害)` → `PlayerCombatStats.ScaledDamage` |
| 暴击 | 概率 `clamp01(CritChance)`；暴击伤害 `× max(1, CritDamage)` |
| 实际开火间隔 | `max(下限, 基础间隔 × CooldownMul × 杰罗特协同 × 冷静风暴0.82)` |
| 间隔下限 | 地狱绝唱满级进化 `0.04`；其余 `0.07` |
| 护甲承伤 | `20 / (20 + max(0, Armor))`（玩家、敌人同一式） |
| 场上预算 | 普通 `min(48, 9 + floor(秒/12))`；BossRush `min(16, 4 + floor(秒/25))` |
| 刷怪间隔 | `max(0.28, 1.05 / (1 + 秒/90))` |
| 怪生命时间 | `1 + 秒 / hpDiv`；标准 `hpDiv=160`；速攻 `110`；无尽再 `min(endlessCaps.hp, …)` |
| 怪移速时间 | `1 + 秒 / moveDiv`；标准 `360`；速攻 `280`；无尽再 `min(endlessCaps.move, …)` |
| 怪接触伤害时间 | `1 + 秒 / 200`；无尽再 `min(endlessCaps.damage, …)` |
| 残烬 | `(地图基础 + 击杀×0.18 + 存活秒/8 + Boss×22) × 诅咒倍率 × 模式系数 × 防刷衰减` |
| 诅咒残烬钳位 | `[1.0, 2.2]` |
| 失败保底 | `地图基础 × 0.3`；胜利再与 `max(40, 保底)` 取大 |
| 防刷 | 同图同星 20 分钟内每多打一局基础再 ×0.8，最低 ×0.4；120 分钟清衰减；无尽不参与 |

**杰罗特协同：** 每带 1 件普通武器冷却 ×0.92，最多 3 件 → 最低 ×0.7787。

**连斩经验：** ≥6 → ×1.1；≥12 → ×1.2；窗口见战斗连斩（经验球额外：连斩≥8 该怪 +2 XP）。

## 11. 残烬与元研究

结算：`残烬 = (基础 + 击杀×0.18 + 秒/8 + Boss×22) × 诅咒积 × 模式 × 衰减`。

诅咒残烬倍率（积后钳 2.2）：护甲 1.20、迅疾 1.25、流血 1.35、瘴气 1.20、精英狂 1.30、掉落稀 1.22、死亡回响 1.38、霜灾 1.28、瘟疫 1.32、混沌 1.40。三诅咒理论积可超 2.2，实际封顶 2.2。

模式：速攻 ×0.85；无尽 ×1.1；其它 ×1。

**示例（无诅咒、无衰减、标准、★1 基础 60）：**

| 对局 | 粗算残烬 |
|---|---:|
| 失败 3 分钟、80 杀、0 Boss | max(18, 60+14+22+0)≈96 |
| 胜利 20 分钟、800 杀、5 Boss | 60+144+150+110 = **464** |
| 同条件 ★5 基础 260 | **664** |

节点花费（残烬）：解锁类 35–90；微加成每级 武器娴熟 45、其余 40。重置树 120（只清微加成，不清内容解锁）。

局外微加成硬顶：冷却 −6%、DOT +16%、生命 +20、暴击 +6%、护甲 +2。另有范围 +0.03、时长 +0.05、抗性 +0.08、拾取 +0.2、吸血 +0.1 等一次性节点。

## 13. 代码 vs 文档 vs JSON 偏差

1. **莫拉伤害：** GDD 表写 13；代码 `13×0.88=11.44`（溃烂「直接伤害 −12%」叠进基础伤害）。面板会显示 11.4，比表低一截。
2. **GDD 血脉包Ⅱ写「暗影」：** 九脉实现是火水土蚀雷冰疫圣混沌，**没有暗影**。
3. **JSON `xp` / `spawnBudget` / `weaponSlots` / `weaponLevelCap` / `replaces`：** 写了但 C# 结构未全部接入，改 JSON 这些键**不会改游戏**。
4. **C# 地图 Fallback** 缺 JSON 的 `move/hazard/eliteEarly`（洞窟/炼狱）。有 StreamingAssets 时以 JSON 为准。
5. **开局 XP 栏默认 32：** 真正升级仍按 30；显示可能闪一下。
6. **README** 仍写「最多 4 件武器 / 10 分钟胜利 / Unity 6」，与 v2.6 不符（文档债，不是平衡数）。

## 14. 合理性分析

总评：**开局清场和局外成长是克制的；标准 20 分钟后半的时间曲线过陡，和无尽硬顶方向相反。**  survivor 原型能玩，但「标准终局 / 无尽长盘 / ★5」三套难度没有同一套标尺。

### 合理的部分

- **角色分化清楚：** 安塔洛等效生命约 215 vs 利兹 112、期望 DPS 139，玻璃与盾分工明确；卡伦用移速 6.0 换输出。局外 +20 生命只相当于杰罗特 +15%，+2 甲约 9% 减伤，符合「不碾压高星」。
- **残烬节奏：** ★1 通关约 400+，节点 35–90，一局能买 1 个中型解锁，不会一轮买空树；防刷 20 分钟 −20% 到 40% 能挡住刷图。
- **开局专武：** 双针 DPS ~100 对 Swarm 16 / Tank 58 足够，避免 v2.5「前 5 级刮痧」。锁敌半径近战 12 / 远程 22–26 合理。
- **DOT 门闩 0.25 s** 与诅咒钳位 2.2、武器栏 8 + 替换 8，方向对。
- **地图主题：** 城市堆甲、绝地堆腐蚀、平原堆伤害，★4/★5 才同时拉生命和伤害，结构清楚。甲 18 → 输出约腰斩，配合 ★5 血 ×2.8，是「必须靠构筑」而不是微调移速能过。

### 风险（建议优先核对实机）

**A. 标准模式移速时间无顶（最高优先级）**  
20:00 移速 ×4.33。Swarm 底板 2.2 → **9.5**，Runner **15.6**，都快过玩家 5.5。4:30 刷怪间隔已触底 0.28，8:00 预算封 48。后半不是「怪变厚」，而是「怪比你快还贴满」。若实机 12 分钟后大量不可风筝死亡，应给标准也加移速硬顶（例如 1.6–2.0），或把 `360` 改到 `600+`。

**B. 标准生命/接触同样无顶，和无尽倒挂**  
20:00 生命 ×8.5、接触 ×7；无尽却在 ×4 / ×3.5 封顶。无尽 20 分钟比标准终局**更好活**。若无尽要当高分压榨，应提高无尽顶或延后封顶；若标准 20 分钟要可通关，应对标准生命/伤害也设顶（例如生命 3.5、伤害 2.5）。

**C. 莫拉偏弱**  
期望 DPS 比杰罗特低约 28%，生命更低，DOT 传染还带 0.4×。除非瘟疫/腐蚀在实机占比很高，否则玩家会感觉「解锁角色是惩罚」。建议：基础伤害保持 GDD 的 13，−12% 只打「非 DOT 直伤」，或把传染系数从 0.4 提到 0.7。

**D. ★5 + 标准终局乘区爆炸**  
生命 8.5×2.8、甲承伤 ~53%、接触再 ×2×7×1.12。单 Swarm 约 380 血、接触过百。只有铺满 8 栏 + 减速/击退才像能站。★5 应绑定「已有完整构筑」，或 ★5 少吃一段时间倍率（例如地图系数替代时间曲线，而不是相乘）。

**E. 绝地腐蚀 21/s**  
杰罗特 130 血、无抗性，站垫 **6 秒** 空血。冲刺无敌只有 ~0.22 s。作为地形压力可以，但 ★3 安全岛若偏少，会变成「看地板游戏」盖过走位打怪。建议实机看安全岛面积；可把 21 降到 14–16，或提高抗性获取。

**F. 神之平原 ★3 伤害 ×1.8 且障碍少**  
接触与吐痰都乘伤害。开阔图最吃走位，但 ×1.8 在中期时间倍率上会非常痛。可考虑平原少给生命、伤害放到 ★3 的 1.4 左右。

**G. 间隔下限 0.07 / 绝唱 0.04**  
杰罗特三武器协同后再叠娴熟 −6%、冷静风暴 ×0.82，远程武器容易顶到下限，攻速装收益变 0。这是 survivor 常见保护，但「冷却牌」后期会变废卡。可接受，或把下限降到 0.05 并削弱弹数成长。

**H. JSON 死字段**  
策划改 `spawnBudget` / `xp` 会以为进了游戏。要么接到 `BalanceTables`，要么从 JSON 删掉以免双源。

### 经验曲线是否够用

升到 20 级累计经验 `19×30 + 14×19×18/2 = 2964`。按场均 6 XP/击杀约 500 杀。20 分钟预算 48、间隔 0.28，理论生成远高于 500，经验够用，卡在「杀得动与否」而不是缺升级。专武节点到 25 级：累计约 `24×30 + 14×24×23/2 = 4584`，★1 标准可到；★5 若后期刮痧可能卡在 12–18，专武进化偏晚——这与「高星靠构筑」一致，但开局弱角色（莫拉）会更痛。

### 建议调参顺序（未改数值，仅建议）

1. 给标准模式加移速硬顶（先测 1.8）。  
2. 统一「终局乘区」：标准与无尽共用生命/伤害顶，或无尽顶高于标准。  
3. 修正莫拉伤害双扣。  
4. 把 JSON 死字段接到代码。  
5. 实机录 ★1 标准、★3 平原、★5 炼狱三条死亡原因（撞速 / 腐蚀 / 接触）。
