# Veinfire — Steam 上架路线

现在还不到接 Steamworks 的时候。等「能稳定玩完一局、愿意发给朋友试」再做下面这些。

## 账号与费用

1. 注册 [Steamworks](https://partner.steamgames.com/)
2. 支付一次性 $100 合作伙伴费用（游戏上线并有收入后可退）
3. 填写税务 / 银行信息（国内开发者按 Steam 当时指引走）
4. 创建 App：类型 Game，名称 **Veinfire**

## 建议发售节奏

1. **可玩 Demo**（1 张图、1 角色、若干升级，约 8～12 分钟）
2. 商店页先上线，开 **愿望单**，挂 Demo
3. 根据反馈补武器、敌人、一到两个角色
4. 正式版 1.0（单机、中文、手柄更好）

## 商店页最低配

- 5 张以上截图（16:9）
- 30～60 秒预告（可以后补，但越早越好）
- 简短介绍：自动射击、一局十来分钟、升级三选一
- 标签：Action Roguelike、Bullet Heaven、Singleplayer、2D
- 支持语言：简体中文（先把这一门做好）
- 标明：单机、不联网也能玩

## 构建与技术（后期）

- Windows 64-bit 是第一平台
- 用 Unity 打独立玩家 PC 包
- 再接 Steamworks.NET：成就、云存档、Overlay
- 关闭开发用的自动作弊键
- 崩溃要少，一局不要卡成幻灯片（敌人多时用对象池，刷怪脚本里已预留 MaxAlive）

## 合规

- 暴力程度按实际画面填年龄分级
- 若只有 Steam 云/成就，隐私政策写清楚即可
- 不要在未完成时标「线上多人」

## 不要过早做的事

- 第一周就接 Steam SDK
- 还没 Demo 就做库存、创意工坊、联机
- 把发行日定死在「系统全部做完」之后
